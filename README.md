# Media Informatics / HCI Thesis Template

A template for Bachelor and Master theses for the Media Informatics / HCI group at University of Tübingen. 

## Get started

1. Clone or download this repository.
2. Open `config.tex`.
3. Fill in your thesis information.
4. Replace the example chapters with your own content.
5. Compile `main.tex`

## Repository Structure

```
.
├── chapters/          Thesis chapters
├── figures/           Images
├── bibliography/      References
├── glossary/          Glossary and acronyms
├── tutorial.tex       Template tutorial
├── config.tex         Thesis configuration
├── HCIthesis.cls      Template class
└── main.tex           Main document
```
